I

THE GUARDIANS

The Python command hooks, in hooks/hooks.json. Exit 2 blocks, and stderr tells the agent why.
Every question bears its Links
question_guard.py pre · PreToolUse, AskUserQuestion
A question is blocked unless the env.py refs Links block sits right above it. Otherwise it floats away.
EXIT 2
Ask with the tool, not in prose
question_guard.py stop · Stop, every turn
A turn that ends on a plain-text question is sent back to the agent.
EXIT 2
The sub-agents only read
agent_guard.py pre · PreToolUse, Bash or PowerShell
investigator and skeptic may run only allowlisted git reads, and never env.py or spec.py. An unknown git command counts as a write.
EXIT 2
Work in the worktree
edit_guard.py pre · PreToolUse, Edit, Write, MultiEdit, NotebookEdit
Edits to a repo in the main checkout are blocked, and the message points to the same file in the item's worktree.
EXIT 2
The Herald
env.py upgrade-config · SessionStart
Not a guard. It adds any new keys to .claude/sdd.json.
WHEN question_guard and edit_guard act only during an sdd flow: this turn ran env.py or spec.py, or an item's progress was written this session.
WHOM agent_guard acts only inside the plugin's own sub-agents. The main chat passes through.
II

THE VIEW

This wall is a designated Desktop view

hooks/register.tsx. The Desktop mod observes and draws, and its one write is each turn's cost. Claude Desktop only: other surfaces pass through.

Setting up

session.startRuns setupDesktop: commands, first read, cost baseline, timers.
session.attachDoes the same when Desktop attaches later.

Commands

command.run · sddSets this chat's item and opens the pane the first time.
sdd-view · sdd-worktrees · sdd-bugsOpen the view, the Worktrees page and the bug manager.
prompt.autocompleteSuggests open items after /sdd.

Tool calls

tool.call · Bash | PowerShellAfter each sdd script run, follows the item it names and refreshes.
tool.call · AskUserQuestionShows the question in the stage's feedback box, where it can also be answered.

Cost & status

turn.start · turn.completeCharges each turn's tokens and dollars to its stage, and notifies once when the item waits on you.
session.measure · session.endTracks context fill and cost, and resets on /clear or /resume.

Drawing

ui.render · SpinnerAdds the item, stage and goal after the spinner word.
ui.render · AbovePromptDraws the status band above the prompt.
ui.render · PaneDraws the sdd view, Worktrees and Bugs panes.
ui.closeNotes which pane closed.
By order of the sdd plugin · Gates are not to be passed from this view
